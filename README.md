# Proyecto3_PNWO

Este proyecto implementa un simulador visual de una Máquina de Turing que permite al usuario ingresar una cadena, seleccionar un lenguaje regular y observar la ejecución paso a paso de cómo la máquina analiza y acepta o rechaza la entrada.
Instrucciones de uso:
1.	Selecciona uno de los lenguajes disponibles en el menú desplegable.
2.	Ingresa una cadena de entrada para analizar.
3.	Presiona el botón “Iniciar simulación”.
4.	Utiliza el botón “Paso a paso” para avanzar manualmente por cada transición.
5.	Si deseas comenzar de nuevo, presiona “Reiniciar”.
6.	El sistema mostrará si la cadena fue aceptada o rechazada.
Ejemplo de ejecución:
Entrada:
Lenguaje: (a|b)*abb  
Cadena: ababb
Resultado: Cadena aceptada por el lenguaje.
